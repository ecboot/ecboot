# API 契约总则（conventions）

全部端点共同遵守；各渠道文件只列差异与端点表。

## 响应与错误

- 统一三段式：`{code, message, data}`；成功 `code=0`。由中间件包装，Res 结构体仅定义 data。
- 错误码分段（在 003 基础上扩展）：`1xxxx` 通用（10001 参数 / 10002 系统+追踪号 / 10003 未登录 / 10004 频控 / 10005 无权限）；`2xxxx` 用户域（20001 验证码 / 20002 锁定 / 20003 禁用 / 20004 微信绑定冲突）；**`3xxxx` 商品域 / `4xxxx` 交易域 / `5xxxx` 促销域 / `6xxxx` 分销域 / `7xxxx` 门店域 / `8xxxx` 后台治理域**；具体码在各域实现时登记于 `internal/errcode`。

## 鉴权三级

| 级别 | 承载 | 说明 |
|---|---|---|
| 公开 | 无 | 游客可调；可选携带会员凭证（身份相关行为如分享上报带 user） |
| 会员 | Bearer token（双凭证，见 D3） | `Authorization: Bearer <token>`；refresh 换新 |
| 管理员 | Bearer 后台 token + 权限点 | 管理组中间件按 `模块:资源:动作` 校验；`is_super` 直通 |

## 通用字段约定

- 分页请求 `page`(默认1)/`pageSize`(默认10,≤100)；分页响应 `total` + `list`。
- ID 对外一律 string（int64 精度）；金额单位元、类型 string 两位小数；时间 RFC3339。
- 手机号响应一律脱敏 `138****1234`；管理端检索仅完整手机号精确匹配。
- 删除语义：主数据为软删（接口表现为不可见）；交易单据无删除接口（取消=状态迁移）。

## 双凭证会话

- 登录返回 `{token, refreshToken}`；token 短效访问、refreshToken 长效换新（`POST /{渠道}/token/refresh`）；登出两者同失效。
