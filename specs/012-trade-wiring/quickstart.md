## 手工验证序列（可选，curl）

1. **积分抵扣修复**：会员有积分余额 → 结算试算勾选积分 → `pointAmount > 0`（修复前恒为 0）。
2. **购物车**：加购 → 改量 → 试算（账本勾稽）→ 移除。
3. **下单与取消**：下单（同 token 两次返回同订单号）→ 详情 → 取消（库存回补/券退回/余额解冻）。
4. **支付闭环**：发起支付（返回 mock 唤起参数）→ 模拟回调 → 订单待发货 + 库存核销；
   **重复回调** → 应答成功但状态不变（幂等）；金额不符回调 → 拒绝且 `pay_callback_log` 留档。
5. **后台订单**：后台列表（状态/关键词）→ 发货（物流公司启用态校验）→ 备注（C 端详情不含）；
   后台取消他单 → 资源释放。
6. **优惠券**：领券（超限→拒绝）→ 我的券（四态）→ 试算可用券匹配（门槛+降序）→ 下单核销 →
   订单取消退回（有效期不变）。
7. **回调公开性**：`POST /shop/pay/notify` 与 `/shop/refund/notify` 无 Bearer 可访问（渠道签名语义）。

## 验收红线（宪法 IV）

任何"完成"声明前，`make test` 与 lint 的实际输出必须为通过；桩数以 `make check-stub` 输出为准。
